1. Inheritance
A child class automatically gets everything from the parent class. So no need to rewrite it. When a class inherits another class it receives the properties and methods of the parent class. Therefore, you create the base class which has the shared behaviour only once and anytime you extend from the base class you get this behaviour for free. The power of inheritance as it relates to large projects is that any changes made to the parent class will naturally be reflected in all of its children and so maintenance is far simpler than would otherwise be the case and the likelihood of having inconsistent behaviour throughout your application is far lower than it otherwise would be.

2. Polymorphism
The same method behaves differently in different classes.It means that different classes can respond to the same method call in their own way

3. Abstraction
Hide complex inner logic and only show what's necessary. It hiding complexity and only exposing what is necessary. 

4. Encapsulation
Protect your data and don't allow direct access from outside. It is about protecting your data by controlling how it is accessed and modified.
